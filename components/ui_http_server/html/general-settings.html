Sendspin pairing
Which Sendspin servers (Music Assistant) may play on this device. Changes here apply at once; only Forget paired servers restarts the device.
To pair Music Assistant: open Settings → Players → this player → Reconfigure player. When it asks to put the device in pairing mode, press the device button briefly (the light turns violet) or Allow pairing here, then type the code. Pair it before requiring pairing: a refused Music Assistant does not come back by itself.
